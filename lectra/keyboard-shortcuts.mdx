If your iPad has a hardware keyboard, such as a Magic Keyboard or Smart Keyboard, you can use shortcuts for the actions you take most. To see the shortcuts that work on the current screen, press and hold the <kbd>Command</kbd> key.

Some shortcuts work only in certain places. Tool shortcuts work only while a document is open, and formatting shortcuts work only while you're typing in a text box.

## Library and documents

| Action | Shortcut | Works in |
|---|---|---|
| New notebook | <kbd>⌘</kbd> <kbd>N</kbd> | Anywhere |
| Scan a document | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>N</kbd> | Anywhere |
| Import a file | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>I</kbd> | Anywhere |
| Search your library | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>F</kbd> | Anywhere |
| Open Settings | <kbd>⌘</kbd> <kbd>,</kbd> | Anywhere |

## Editing

| Action | Shortcut | Works in |
|---|---|---|
| Undo | <kbd>⌘</kbd> <kbd>Z</kbd> | Open document |
| Redo | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> or <kbd>⌘</kbd> <kbd>Y</kbd> | Open document |
| Paste what you copied with the lasso | <kbd>⌘</kbd> <kbd>V</kbd> | Open document |

## Tools

These shortcuts switch tools in an open document. They pause while you're typing in a text box, so the letters reach your text.

| Tool | Shortcut |
|---|---|
| Pen | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>P</kbd> |
| Highlighter | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>H</kbd> |
| Eraser | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>E</kbd> |
| Select (lasso) | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>L</kbd> |
| Text | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>T</kbd> |
| Sticky Note (the **Note** tool) | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>K</kbd> |
| Shapes | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>G</kbd> |
| Scroll (the same as **Read** in the top bar) | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>D</kbd> |
| Show or hide the ruler | <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>U</kbd> |

## View and navigation

| Action | Shortcut |
|---|---|
| Zoom in | <kbd>⌘</kbd> <kbd>+</kbd> or <kbd>⌘</kbd> <kbd>=</kbd> |
| Zoom out | <kbd>⌘</kbd> <kbd>-</kbd> |
| Zoom to fit | <kbd>⌘</kbd> <kbd>0</kbd> |
| Next page | <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>↓</kbd> or <kbd>→</kbd> |
| Previous page | <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>↑</kbd> or <kbd>←</kbd> |
| Show or hide page thumbnails | <kbd>⌥</kbd> <kbd>⌘</kbd> <kbd>S</kbd> |
| Find in this document | <kbd>⌘</kbd> <kbd>F</kbd> |

The left and right arrow keys turn pages only while you aren't typing in a text box.

## Text formatting

These shortcuts work while you're typing in a text box. They apply to the whole box. To learn more, see [Add typed text](/lectra/text).

| Action | Shortcut |
|---|---|
| Bold | <kbd>⌘</kbd> <kbd>B</kbd> |
| Italic | <kbd>⌘</kbd> <kbd>I</kbd> |
| Underline | <kbd>⌘</kbd> <kbd>U</kbd> |

## Shortcuts in code tools

The code editor, terminal, and Python notebooks have their own shortcuts. See [Code editor](/lectra/code-editor), [Terminal](/lectra/terminal), and [Jupyter notebooks](/lectra/jupyter-notebooks).

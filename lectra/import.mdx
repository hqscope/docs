You can bring a file into Lectra from the Files app, from another app's share sheet, by dragging it in, or by sending it from Scope in your browser. PDFs open as they are. Images, slides, and other documents become PDFs so you can write on them.

## Supported files

| File | What happens |
|---|---|
| PDF | Opens as a document you can mark up. |
| Images: PNG, JPEG, HEIC, HEIF, GIF, WebP, TIFF | Each image becomes a one-page PDF. |
| Slides and documents: PowerPoint (`.pptx`, `.ppt`), Keynote, Word (`.docx`, `.doc`), Pages, Excel (`.xlsx`, `.xls`), Numbers, rich text, plain text, CSV, and HTML | Lectra converts the file to a PDF, laid out the way it would print. Slides are laid out in landscape. While it works, you see **Preparing *file name*…**. |
| Lectra documents (`.lectra`, or a PDF shared from Lectra as a **Lectra Document**) | Opens with your handwriting, images, and notes still editable. To learn more, see [Open a Lectra document](#open-a-lectra-document). |
| Jupyter notebooks (`.ipynb`) | Opens in **Projects**. To learn more, see [Jupyter notebooks](/lectra/jupyter-notebooks). |

<Note>
  The **Import PDF** file picker accepts PDFs, images, `.lectra` files, and `.ipynb` notebooks. To bring in slides or Word, Pages, or Excel files, drag them in, or open them in Lectra from the Files app or the share sheet.
</Note>

## Import a file from the Files app

<Steps>
  <Step title="Go to the right folder">
    In your library, open the folder where you want the file to go. To put it at the top level, stay in **Documents**.
  </Step>
  <Step title="Open the New menu">
    Tap **New**, then tap **Import PDF**. You can also press <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>I</kbd>.
  </Step>
  <Step title="Choose the file">
    In the file picker, browse to the file and tap it. You can import one file at a time.
  </Step>
</Steps>

The file is added to the folder you were in and opens right away.

## Open a file in Lectra from another app

You can send a file to Lectra from the Files app, Mail, Safari, and most other apps.

<Steps>
  <Step title="Share the file">
    In the other app, open the file and tap **Share**. In the Files app, you can also touch and hold the file, then tap **Share**.
  </Step>
  <Step title="Choose Lectra">
    In the row of apps, tap **Lectra**. If you don't see it, tap **More** and look for it in the list.
  </Step>
  <Step title="Choose where it goes">
    In **Add to Lectra**, choose one of the following options:
    - **New document**: tap folders to choose where the file goes, then tap **Import to "folder name"**.
    - **Add to a document**: search for a document and tap it. The file's pages are added to the end of that document.
  </Step>
</Steps>

### Use Send to Scope in the share sheet

The share sheet also offers **Send to Scope**. It opens a small Lectra card with two buttons:

- **Open in Lectra** adds the file to your library. Choose **New document** or **Add to a document**, as described in the previous section. When you see **Added to Lectra.**, the file appears the next time you open Lectra. You don't need an account for this.
- **Send to Scope** sends the file to the Scope extension in Chrome. You must be signed in, and the file must be 25 MB or smaller. To learn more, see [Send files between devices](/lectra/send-between-devices).

<Note>
  The share sheet card works only after you've opened Lectra at least once. If you see **Open Lectra once, then share again.**, open Lectra and try again.
</Note>

## Drag files into Lectra

When Lectra is next to another app in Split View or Slide Over, you can drag files straight into your library.

<Steps>
  <Step title="Open both apps">
    Open Lectra and the app that has your files, such as Files, side by side.
  </Step>
  <Step title="Choose the destination folder">
    In Lectra, open the folder where the files should go.
  </Step>
  <Step title="Drag the files">
    Touch and hold a file, then drag it onto the Lectra library. To drag several files, touch and hold one file, then tap others with another finger before you drag.
  </Step>
</Steps>

The files are added to the folder you're viewing. You can't drop files into **Scope Inbox**.

## Add pages from a file to a document

To add pages from another PDF or an image to a document you already have, use either of these methods:

- **From the editor**: open the document, open the pages panel, tap **Insert**, then tap **From Files…**. The pages go after the current page. To learn more, see [Manage pages](/lectra/annotate#manage-pages).
- **From another app**: share the file to Lectra and choose **Add to a document**. The pages go at the end of the document you pick.

## Files from Scope

If you use the Scope extension in Chrome, you can send a course file to your iPad in one tap. It arrives in **Scope Inbox**, sorted into folders by course. If you send slides, a Word, Pages, or Excel file, or an image, Lectra converts it to a PDF when it arrives.

### Before you begin

- Sign in to Lectra with the same account you use in Scope.
- In Scope, turn on **Send to Lectra** in Settings. To learn how, see [Send files from Chrome to your iPad](/chrome/send-to-ipad).

### Find a file you sent

<Steps>
  <Step title="Open Scope Inbox">
    In the sidebar, tap **Scope Inbox**. On a narrow window, tap **Inbox** in the tab bar.
  </Step>
  <Step title="Open the file">
    Tap a course folder, then tap the file. New files are marked **New**.
  </Step>
</Steps>

While a file is on its way, its thumbnail says **Arriving…**. If the download fails, it says **Couldn't download · Tap to retry**. Tap it to try again.

When a file arrives while you're in the library, a message says "*title* arrived from Scope". Tap **Open** to open it.

If nothing has arrived yet, tap **Check for New Files**. When everything is in, you see **You're up to date**.

### Keep a file in your own folders

Files in **Scope Inbox** stay in their course folders until you move them.

- To move one file into **Documents**, tap **Move** next to it.
- To move a whole course folder into **Documents**, tap **Move all**.
- To move a folder somewhere else, touch and hold it, then tap **Move to folder…**.

After you move something, you can choose whether to open it right away.

### Open new files automatically

To have files from Scope open as soon as they arrive, go to **Settings** > **App** and turn on **Open files from Scope automatically**. A file that arrives while you're browsing your library opens right away. While you're writing, it waits for you to tap it.

To get a notification when a file arrives while Lectra is closed, tap **Notify Me About New Files** in the same section.

## Open a Lectra document

A Lectra document is a full copy of a document, with handwriting, images, and notes you can still edit. It can be a `.lectra` file, or a PDF that someone shared from Lectra using the **Lectra Document** option. To learn how to create one, see [Export and share](/lectra/export-and-share#share-a-document).

Open it the same way as any other file. If you already have the same document in your library, Lectra asks what to do:

| Option | What it does |
|---|---|
| **Replace my copy** | Replaces your copy with the one you opened. The description tells you whether this updates your copy to a newer version or rolls it back to an older one. |
| **Keep both** | Adds the opened file as a separate document. Nothing you have now changes. |
| **Cancel** | Leaves your library as it is. |

When it finishes, you see **Added "*title*".** or **Restored "*title*".** If part of the document was damaged, the message adds **Some notes didn't arrive intact.**

<Note>
  A PDF shared as a **Lectra Document** also opens as an ordinary PDF in any other app, with the handwriting part of the page. Only Lectra can open the editable copy inside it.
</Note>

## Name suggestions for imported files

If Apple Intelligence is on and an imported file has a vague name, Lectra can suggest a better one. You see **Rename this file?** with the suggestion. Tap **Rename** to accept it or **Keep Name** to leave it. Lectra never renames a file without asking. To learn more, see [Apple Intelligence](/lectra/apple-intelligence).

## Troubleshooting

<AccordionGroup>
  <Accordion title="That file type isn't supported yet">
    Lectra can't open this kind of file. Nothing in your library changed. Save or export the file as a PDF in the app that made it, then import the PDF.
  </Accordion>
  <Accordion title="This PDF needs a password to open">
    Lectra can't open password-protected PDFs. Remove the password in the app that made the PDF, then import it again.
  </Accordion>
  <Accordion title="This PDF looks damaged or empty">
    The file may not have downloaded completely. Download it again from its source, then import it again.
  </Accordion>
  <Accordion title="Couldn't add those files">
    Some files may be locked, damaged, or a type Lectra doesn't open. Nothing in your library changed. Try adding the files one at a time to find the one that fails.
  </Accordion>
  <Accordion title="Lectra doesn't appear in the share sheet">
    Scroll to the end of the row of apps and tap **More**. Find Lectra in the list and turn it on, or drag it into **Favorites**.
  </Accordion>
  <Accordion title="A file from Scope hasn't arrived">
    Check that Lectra and Scope are signed in to the same account and that your iPad is online. In **Scope Inbox**, tap **Check for New Files**. To learn more, see [Troubleshooting](/lectra/troubleshooting#files-from-scope-dont-arrive).
  </Accordion>
</AccordionGroup>

This page lists changes you can use today in the Scope extension, Lectra, and Polya, newest first. The Scope extension and Lectra update through the Chrome Web Store and the App Store. Polya is a website, so its changes reach you the next time you open it.

<Update label="October 16, 2026" description="Polya">
  ## Study for exams in Polya

  - **Study tab.** Each course now has a **Study** tab. Add an exam with its date and what it covers, mark your formula sheet and past exams, and get a suggested topic map that you can edit. To learn more, see [Prepare for an exam](/polya/study).
  - **Exam-style practice.** Practice numeric, multiple-choice, and select-all questions written from your course materials. Polya checks each answer against the question's answer key. Questions you miss come back after a day, and each topic shows how far along you are.
  - **Upload your own PDFs.** Add PDFs to a course yourself, up to 30 MB and 300 pages each.
  - **Math in chat.** Equations in Polya's answers now display as formatted math.
</Update>

<Update label="October 14, 2026" description="Lectra 10.0">
  ## Lectra 10.0

  - **Remote Desktop assistant.** Ask the assistant to open a website, run a search, or launch an app on your Mac, and it does it in one step. It can also show you the text of a page on your Mac. It asks before it acts unless you turn on **Auto-run**. The assistant uses your own Anthropic API key. To learn more, see [Lectra for Mac](/lectra/mac).
  - **More paper for new pages.** New pages can use blank, lined, grid, dotted, or Cornell paper.
  - **Recording controls.** The recording controls stay within reach and out of your way during a lecture. If Lectra can't use the microphone, it links you to the setting in the Settings app.
  - **Recently Deleted.** Lectra asks before it deletes a document, then moves it to **Recently Deleted** and offers **Undo**. Deleted documents stay there for 30 days, and you can restore them. Open it from **More library options** (•••) in your library.
  - **Arriving documents.** A document sent from Scope shows **Arriving…** while its pages download. If the download fails, the document says so, and you can tap it to try again.
  - **Clearer messages.** **Check for New Files** tells you when it couldn't check, instead of saying you're up to date. Error messages throughout the app use plain sentences.
  - **Accessibility and layout fixes** throughout, including **Move Left** and **Move Right** for documents in split view.
</Update>

<Update label="October 12, 2026" description="Scope extension 12.0">
  ## Scope extension 12.0

  - **Ask Scope reads more of your course.** **Ask Scope** now looks through the full text of Canvas pages, syllabi, and assignment descriptions, not only their titles.
  - **Select from Lectra on Canvas.** On a Canvas assignment's file upload page, choose **Select from Lectra** to attach a PDF from your Lectra library. Scope adds the file. It never replaces a file you already attached, and it never submits.
  - **Send to Lectra from Google Drive** now works when you're signed in to more than one Google account.
  - **Smaller download.** The extension takes up less space.
</Update>

<Update label="October 12, 2026" description="Polya">
  ## Polya reads scanned pages

  - **Scanned PDFs.** Polya now reads course PDFs whose pages are pictures, such as scanned readings and slides saved as images. Citations still point to the right page.
  - **More reliable imports.** One bad character in a PDF or lecture transcript no longer stops the whole file from importing. Long imports pick up where they stopped.
  - **New conversation** button to start over without reloading the page.
  - The question box grows as you type, so a long problem stays visible.
  - Long course names no longer push **Study** and the options menu off a phone screen.
  - Long links and code wrap inside chat messages, and your own line breaks are kept.
  - A cited PDF always has an **Open the PDF** link, because phone browsers don't show PDFs inside the page.
  - If your courses fail to load, you see a notice with a way to try again.
</Update>

<Update label="October 4, 2026" description="Polya">
  ## Polya in Claude and ChatGPT

  You can now connect Polya to Claude or ChatGPT. The assistant can list your Polya courses, read the study mode you chose for each, and search your readings, slides, pages, and lecture transcripts with citations. It checks your study mode again before each new question. The connection can only read; it doesn't change anything in Polya or Canvas. In **Practice** mode, the search never returns answer keys.

  To set it up, see [Use Polya in Claude](/polya/claude) and [Use Polya in ChatGPT](/polya/chatgpt).
</Update>

<Update label="October 4, 2026" description="Scope extension 11.0.8 and 11.0.10">
  ## Scope extension 11.0.8 and 11.0.10

  - **A clear first step.** A new install opens a page that says **Scope is ready**, with one button that opens Canvas, so Scope can find your courses.
  - **Plain error messages.** Errors explain what happened in a few calm sentences. For example, if you're offline when you send a PDF to Lectra, Scope says so and tells you the PDF is still there.
  - **Clear Scope data on this browser.** A new control in **Settings** removes what Scope saved in your browser.
  - **A calmer browser.** Scope no longer slows Chrome down while it reads the PDFs in a large course.
  - The search bar works with screen readers. It's announced as a dialog, and status changes are read out.
  - The due-date filters work: type filters, a course filter you can clear, and an overdue count that updates when you dismiss an item.
  - Searching the text inside images was removed. Text inside PDFs is still searchable.
</Update>

<Update label="September 25, 2026" description="Scope extension 11.0.6">
  ## Scope extension 11.0.6

  - **Your search index stays on your computer.** Scope no longer saves a copy of your course index to your Scope account. Copies saved by earlier versions were deleted on October 12, 2026.
  - **One search bar.** The side panel is gone. Everything it did now lives in the search bar: press <kbd>⌘</kbd> <kbd>K</kbd> on a Mac or <kbd>Ctrl</kbd> <kbd>K</kbd> on Windows and ChromeOS. When you open a set of results together, Scope can put them in a named tab group if you allow it.
  - **Smoother search.** Search stays responsive while you type, even in a large course.
  - Scope no longer runs on your school's sign-in and sign-out pages.
</Update>

<Update label="September 17, 2026" description="Lectra 9.0">
  ## Lectra 9.0

  - **Tool wheel.** Press and hold with two fingers anywhere on the page to open a ring of tools where your fingers are. It has the same tools as the dock. Tap outside the ring to close it.
  - **A simpler dock.** Each tool in the dock is now its icon alone, and only the tool you're holding has an outline.
  - **Documents from Scope open the first time.** If you tap a document while its pages are still downloading, Lectra waits for the pages and then opens it.
  - **Your shared copy stays current.** Lectra keeps the marked-up copy of each document you share with Scope up to date, even if you leave the document open, so what you send back has your ink on it.
  - Redesigned top bar, floating tool picker, paper setup sheet, and sheet for moving documents between folders.
  - You can name a folder **Imported** again.
  - While a lecture is recording, the recording controls no longer cover the page number and the pages rail.
</Update>

<Update label="September 1, 2026" description="Lectra 8.0">
  ## Lectra 8.0

  - **Lecture recording.** Record a lecture while you take notes in Lectra. To learn more, see [Record lectures](/lectra/record-lectures).
</Update>

<Update label="August 26, 2026" description="Lectra 7.0">
  ## Lectra 7.0

  - **Keyboard shortcuts in the editor.** Shortcuts from the menu bar now reach the document you're working in, including in split view.
  - **Rebuilt tool picker.** The floating tool picker sits closer to the page and no longer covers the line you're writing on.
  - **Saved signatures.** Lectra now offers to save a signature you draw, so you can reuse it on later PDFs.
  - Text boxes keep their size when the page scales.
</Update>

<Update label="August 19, 2026" description="Scope extension">
  ## Counting people who use Scope

  The Scope extension now sends a short signal when you use it, so Scope can count how many people use it, including people who never sign in. The signal contains a random number made on your device, which product and platform it is, and the version. It never includes your searches, the pages you visit, course or file names, or anything you read or write. To learn more, see [Privacy at a glance](/get-started/privacy#how-scope-counts-usage).
</Update>

<Update label="August 14, 2026" description="Scope extension">
  ## Sending to Lectra asks first

  When a PDF you send is already in your Lectra library, Scope now says so and asks what to do: send a copy, or replace the one in Lectra. Replacing keeps your notes with the document.
</Update>

<Update label="August 4, 2026" description="Scope extension 11.0">
  ## Help with class registration at UC Berkeley

  In UC Berkeley's Schedule Planner, hover an instructor to see their ratings, the distribution behind the average, and student comments, with the same course's reviews first. Hover a meeting time to see how it fits your week and where the building is. To learn more, see [Plan classes in Berkeley's Schedule Planner](/chrome/berkeley-schedule-planner).
</Update>

<Update label="July 29, 2026" description="Scope extension">
  ## Course indexing no longer gets stuck

  A course could stall while Scope read its materials, often in the high 90s, and never finish. Now a file that can't be read is skipped and noted, so one bad file costs you that file instead of the whole course. The progress Scope shows matches what it actually read.
</Update>

<Update label="July 28, 2026" description="Scope">
  ## Canvascope is now Scope

  Same team and same apps, with a shorter name. You don't need to reinstall anything. Your courses, notes, account, and sign-in carry over, and old links redirect to the new ones.
</Update>

<Update label="July 7, 2026" description="Lectra Receiver for Chrome 1.0">
  ## Lectra Receiver for Chrome

  Lectra Receiver is now on the Chrome Web Store. Use it to send PDFs from your browser to Lectra, receive files sent back from Lectra, and attach Lectra PDFs on Gradescope. To learn more, see [Lectra Receiver for Chrome](/lectra/receiver).
</Update>

<Update label="July 1, 2026" description="Lectra 1.0">
  ## Lectra is on the App Store

  Lectra arrived on the App Store as **Lectra Notes**, a free app for iPad and iPhone. Import PDFs, organize your library, and read and mark up pages with Apple Pencil. Receive PDFs you send from the Scope extension. To get it, see [Install Lectra](/lectra/install).
</Update>
